A. English


★★★★★★ Important Reminder ★★★★★★

1. Before running, unzip the file first.
2. Before running the firmware upgrade, close the web driver first.
3. When updating the firmware, make sure the driver is turned off.
4. If the progress bar of the firmware upgrade tool gets stuck:
   - For the mouse firmware: unplug and replug the mouse.
   - For the receiver firmware: unplug and replug the receiver.

Update Steps:
1. Make sure the web driver is closed.
2. Plug the receiver into your computer, run "Step1-Receiver_09.02.exe", and wait until you see "Pass". Then close the software.
3. Connect the mouse to your computer using a data cable, run "Step2-Fen_Pro_Mouse_09.04.exe", and wait until you see "Pass". Then close the software.
4. Open the web driver, click the "Reset" button, and reconfigure your preferred mouse settings at www.mouse.xyz, www.mouse.wiki, www.mouse.fit, or www.mouse.中国.

Once you have completed the above steps, the update is finished. You can now use the mouse as needed. If you encounter any issues, please contact us via email at support@g-wolves.com.


B. Chinese


★★★★★★ 重要提醒 ★★★★★★

1. 运行之前，请先解压缩文件。
2. 运行固件升级之前，请先关闭网页驱动。
3. 固件更新时请关闭驱动程序。
4. 如果固件升级工具运行时进度条卡住不动：
   - 鼠标固件：重新插拔鼠标。
   - 接收器固件：重新插拔接收器。

更新步骤：
1. 确保网页驱动已关闭。
2. 将接收器插入电脑，运行 "Step1-Receiver_09.02.exe"，等待看到 "Pass" 后关闭此软件。
3. 使用数据线将鼠标连接到电脑，运行 "Step2-Fen_Pro_Mouse_09.04.exe"，等待看到 "Pass" 后关闭此软件。
4. 打开网页驱动，点击 "Reset" 按钮，重新设置自己习惯的参数。访问 www.mouse.xyz、www.mouse.wiki、www.mouse.fit 或 www.mouse.中国 进行配置。

完成以上步骤后，更新即告完成，您可以正常使用鼠标。如遇到任何问题，请通过邮件 support@g-wolves.com 联系我们。
