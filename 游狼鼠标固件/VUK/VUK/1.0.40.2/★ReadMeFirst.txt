A. English：


★★★★★★ Important reminder ★★★★★★

1. Before running, unzip the file first
2.When updating firmware, the driver should be turned off.
3. If the progress bar of the mouse firmware program gets stuck while running the firmware upgrade tool, unplug and plug the mouse again. If the progress bar of the mouse receiver firmware program gets stuck, try unplugging the mouse receiver again.

Update Steps: 
1. Connect the mouse to the computer using a data cable and run ' VUK 8K Mouse '. Wait until you see "Pass", then close the software and proceed.
2. Plug the receiver into the computer , run  '  G-Wolves 8k Receiver  ', Wait until you see "Pass", then close the software.Then switch on the mouse power at the bottom.
3. After the wireless mouse can function properly, visit htmplus.mouse.xyz  or htmplus.mouse.fit to adjust mouse settings.
Following these 3 steps completes the update process, allowing you to use the mouse normally.If you encounter any issues, please contact us via email at support@g-wolves.com.
