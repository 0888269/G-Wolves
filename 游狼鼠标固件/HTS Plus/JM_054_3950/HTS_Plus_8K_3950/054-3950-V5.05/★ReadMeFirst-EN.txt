                    HTS PLUS 8K Firmware Update Guide
═══════════════════════════════════════════════════════════════════════════════

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚠️  IMPORTANT REMINDER (Please read carefully before updating)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Unzip the file before running
2. Disable the driver when updating firmware
3. Ensure the mouse works with only the data cable connected
   → If not, check the cable connection or try a different cable
4. Use the original black high-speed data cable for the receiver
5. Unplug other mice before starting the update
6. Do not close the update tool during the firmware update process

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 UPDATE STEPS (Follow in order)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1️⃣ — Update Receiver Firmware
───────────────────────────────────────────────────────────────────────────
   1. Connect the receiver to your PC using the data cable
   2. Run program: Receiver_V5.01.exe
   3. Wait for success notification, then close the software

───────────────────────────────────────────────────────────────────────────

Step 2️⃣ — Update Mouse Firmware
───────────────────────────────────────────────────────────────────────────
   1. Connect the mouse to your PC using the data cable
   2. Run program: HTS_PLUS_8K_3950-V5.05.exe
   3. Wait for success notification, then close the software

───────────────────────────────────────────────────────────────────────────

Step 3️⃣ — Driver Reset & Parameter Configuration
───────────────────────────────────────────────────────────────────────────
   1. Confirm the wireless mouse is working properly
   2. Visit: www.mouse.xyz or www.mouse.fit or www.mouse.中国
   3. ⚠️ Click the [Reset] button to reload default settings (Important!)
   4. Configure your preferred settings (DPI, polling rate, RGB, etc.)

───────────────────────────────────────────────────────────────────────────

✅ Update Complete!
