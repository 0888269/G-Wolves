                                       How to update firmware
1. Reset PC
2. Plug the mouse Whith cable to computer. 
3. Open and run  HTS Plus 4K Mouse 01.00.23.00
    Untill see "PASS"
    Close  HTS Plus 4K Mouse 01.00.23.00
4. Plug in the wireless USB receiver.
5. Open and run  HTS Plus 4K Receiver 01.00.23.00
    Untill see "PASS"
    Close  HTS Plus 4K Receiver 01.00.23.00
6. Open Power switch of mouse.
8.  Use your wireless mouse.

OK!

PS: If your wireless mouse becomes unusable after a firmware update, you can use this tool to pair the mouse and receiver.
